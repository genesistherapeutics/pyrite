# Pyrite — a protein–ligand pose-ranking benchmark

**Pyrite** is a pairwise pose-ranking dataset: for each item, two docked protein–ligand
poses (A and B) of the same complex are provided, and the task is to choose which pose is
closer to the experimental (crystallographic) binding mode. The "closer" pose is the label.

- **750 pose pairs** across **177 crystal structures** / **120 proteins**, all derived from
  public RCSB PDB entries (177 unique PDB IDs).
- Each pose carries **3D ligand coordinates**, protein–ligand **interaction fingerprints**,
  and a rich set of **physics/geometry metrics** (MM-GBSA binding energy, Mogul torsion
  validity, torsion strain, PoseBusters validity, pose-shape descriptors, …).
- Every pair is tagged with **pre-/post-AlphaFold3-cutoff** (`released_after_af3_cutoff`),
  **UniProt family**, deposition/release dates, and ligand metadata — enabling clean
  train/test-style splits and per-family / temporal analysis.

## Files (`data/`)

| file | description |
|---|---|
| `pyrite_v6.1_curated.{csv,parquet}` | the benchmark: 750 pairs × 113 columns (inputs, 3D coords, metrics, labels, metadata) |
| `pyrite_grpo_predictions.{csv,parquet}` | predictions of a reasoning LLM (Qwen3.8-27B, GRPO-tuned) on each pair |

## Task & label

- `correct` ∈ {A, B} — the pose closer to the crystal structure (ground truth), by RMSD.
- `pair_kind` — `good_bad` (one clearly better pose; "easy") vs `good_maybe` (both plausible; "subtle").
- Scoring convention used in the paper: **mean per-structure accuracy** — per-pair correctness
  averaged within each `structure_id`, then averaged over structures (equal weight per
  structure), reported overall and split by `released_after_af3_cutoff`.

## Reference model: Qwen3.8-27B-GRPO

A reasoning LLM (Qwen3.8-27B) RL-tuned with GRPO to pick the crystal-closer pose from the
tabular features (no raw coordinates). Its per-pair prediction is in
`pyrite_grpo_predictions.csv` (`grpo_pred`, `grpo_correct`).

**Accuracy on Pyrite (v6.1 curated):**

| metric | value |
|---|---|
| per-pair (pooled) accuracy | **0.669** |
| mean per-structure accuracy — overall | **0.611** |
| mean per-structure accuracy — pre-AF3 | 0.575 |
| mean per-structure accuracy — post-AF3 (held-out / novel complexes) | **0.687** |

## Key columns

- **Identity/metadata:** `pair_id`, `structure_id`, `pdb_id`, `uniprot_id`, `uniprot_name`,
  `uniprot_family`, `uniprot_description`, `canon_smiles`, `is_drug_like`,
  `deposition_date`, `release_date`, `released_after_af3_cutoff`.
- **Label:** `correct`, `pair_kind`.
- **3D structure:** `pose_A`, `pose_B` (ligand atoms + coordinates, text format),
  `pose_interactions_A/B` (residue-level interaction fingerprints).
- **Metrics (per pose, `_A`/`_B`):** `mm_step1_binding_energy` (MM-GBSA), `metric_pb_valid`
  (PoseBusters), `metric_mogul_*` (torsion/ring validity), `metric_*_torsion_strain`,
  `metric_geom_*` (radius of gyration, asphericity, extent, contacts), interaction counts,
  pose-overlap shape/color, and A–B difference metrics.
- `MM_correct` — 1 if the lower-MM-GBSA-energy pose is the crystal-closer one (a convenience flag).

> Note: `metric_rmsd_*`, `pose_rmsds_*`, `metric_lddt_pli_*`, and `metric_gt_interaction_*`
> are computed against the crystal structure and therefore leak the label — use them for
> analysis only, not as model inputs.
